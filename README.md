# OpenRouter Video

Простое нативное GUI-приложение для генерации говорящего аватара через
OpenRouter, модель `heygen/avatar-iv`. Интерфейс на русском.

## Запуск

Для работы с проектом используется только `uv`. Поддерживается Python 3.9+
с PySide6 (macOS, Windows или Linux). Зависимости описаны в `pyproject.toml`,
точные версии зафиксированы в `uv.lock`.

### Напрямую из GitHub

После публикации проекта в
[matthewrv/openrouter-video](https://github.com/matthewrv/openrouter-video)
его можно запускать и устанавливать без ручного клонирования репозитория.
Нужны установленные `uv` и Git.

Разовый запуск в изолированном окружении:

```bash
uvx --from "git+https://github.com/matthewrv/openrouter-video.git" openrouter-video
```

Постоянная установка команды:

```bash
uv tool install "git+https://github.com/matthewrv/openrouter-video.git"
openrouter-video
```

Обновление установленной версии из GitHub:

```bash
uv tool upgrade openrouter-video
```

По умолчанию используется основная ветка репозитория. Для установки
конкретного тега или коммита добавьте `@TAG` или `@COMMIT` к Git URL,
заменив `TAG` или `COMMIT` нужным значением.

### Локальный запуск через uvx

Из любого каталога:

```bash
uvx --from /Users/matthewrv/Documents/openrouter_video openrouter-video
```

Из каталога проекта:

```bash
uvx --from . openrouter-video
```

`uvx` сам создаёт изолированное окружение и устанавливает зависимости.
Вручную создавать `.venv` не нужно. Первый запуск требует интернета.
Проверка установки без открытия окна:

```bash
uvx --from . openrouter-video --version
uvx --from . openrouter-video --help
```

Для постоянной установки команды:

```bash
uv tool install /Users/matthewrv/Documents/openrouter_video
openrouter-video
```

Если `uv` сообщает, что каталог команд не находится в `PATH`, выполните
`uv tool update-shell` и откройте новый терминал.

После изменений в исходниках обновите постоянную установку:

```bash
uv tool install --force /Users/matthewrv/Documents/openrouter_video
```

История и сохранённый токен не зависят от временного окружения `uvx`:
используются те же каталог данных и системное хранилище паролей.

Пакет пока не опубликован в PyPI: используйте `--from` с Git URL,
локальным путём или собранным wheel, а не просто `uvx openrouter-video`.

### Работа с исходниками через uv

```bash
cd /Users/matthewrv/Documents/openrouter_video
uv sync --locked
uv run --locked openrouter-video
```

`uv` управляет окружением проекта автоматически; активировать его вручную
не нужно. Для обновления зафиксированных зависимостей используйте
`uv lock --upgrade`, затем `uv sync --locked`.

На Linux для Qt может потребоваться установленная системная графическая среда.

## Использование

1. Нажмите «Настроить токен» и введите API-токен OpenRouter.
   Опционально сохраните его в системном хранилище паролей
   (Keychain на macOS, Credential Manager на Windows, Secret Service на Linux).
   Без этой опции токен хранится только в памяти. Также поддерживается
   переменная окружения `OPENROUTER_API_KEY`.
2. Выберите референсное изображение PNG/JPEG/WebP/GIF, до 20 МБ.
3. Введите текст в окне или выберите текстовый файл UTF-8, до 1 МБ.
4. Укажите `voice_id` HeyGen.
5. При необходимости задайте длительность и разрешение (подробности ниже).
6. Нажмите «Создать видео» и подтвердите отправку платного запроса.
7. Результат появится в истории; окно не блокируется во время запросов.

В верхней части окна можно выбрать светлую или тёмную тему.
Выбор сохраняется и восстанавливается при следующем запуске.

Источники текста взаимоисключающие: в режиме файла поле ввода текста
заблокировано; в режиме ручного ввода заблокированы путь к текстовому файлу
и кнопка его выбора. При переключении уже введённые значения сохраняются,
но отправляется только выбранный источник.

### Длительность и разрешение

- «Длительность» — целое число секунд (`duration`). По умолчанию «Не задавать»
  (значение 0): параметр отсутствует в запросе.
- По умолчанию выбрано «Не задавать (по выбору модели)»: параметры `size`
  и `resolution` отсутствуют в запросе, в том числе после выбора картинки.
- При выборе «Исходное» рядом с вариантом отображается
  её ширина и высота в пикселях. В запрос передаётся `size`, например
  `1024x1024`. При изменении пути размер определяется заново; при отправке
  он проверяется по снимку фактически прочитанного файла.
- Стандартные варианты — `720p` и `1080p`; они передаются как `resolution`.
- «Своё» включает целочисленные поля ширины и высоты; передаётся `size`
  в формате `WIDTHxHEIGHT`. `size` и `resolution` одновременно не отправляются.

Эти значения сохраняются в истории и восстанавливаются в редактируемой копии.
В старой истории без этих параметров показывается «Не задана / По выбору модели»;
при копировании старого запроса параметры остаются незаданными.
В новой копии с исходным размером изображение читается заново, поэтому
изменившийся файл может дать другой размер.

Это параметры генерации, а не жёсткий денежный лимит или гарантированный
способ устранить HTTP 402. Поддержка конкретной длительности, стандартного
разрешения или произвольного размера зависит от модели и провайдера:
API может отклонить неподдерживаемое сочетание. Приложение не меняет размер
референсной картинки и не выполняет платных пробных запросов автоматически.

### Результаты

- POST `/api/v1/videos` отправляется **один раз**, автоматических повторов нет.
- GET `polling_url` выполняется примерно каждые 30 секунд.
  При сетевых ошибках интервал растёт до 5 минут.
- После `completed` сохраняются `unsigned_urls`; проверка продолжается до
  появления `urls`, но не дольше часа после первого замеченного завершения.
  В любой момент доступна кнопка «Обновить статус / ссылки».
- Ссылки отображаются короткими кнопками; «Копировать ссылку» копирует
  полный адрес, включая параметры.
- `unsigned_urls` требуют авторизации: клик по такой ссылке предлагает
  скачать видео из приложения с токеном. Сам токен не передаётся браузеру.
- `urls` открываются в браузере, их также можно скачать.
  Подписанные ссылки могут истекать. История не является бессрочным
  хранилищем видео — скачайте важные результаты отдельно.
- При перенаправлении скачивания на другой сервер заголовок авторизации
  удаляется; токен отправляется только HTTPS API OpenRouter.

### История и копирование

Успешные записи подсвечиваются зелёным, записи с ошибками, отменённые,
истёкшие и с неподтверждённой отправкой — красным. Ожидающие и выполняющиеся
запросы без ошибок остаются нейтральными. Оттенки адаптируются к светлой
или тёмной теме, включая выделенную запись, и меняются сразу при переключении.
Завершённое видео остаётся зелёным даже при последующей ошибке обновления ссылок.

После отправки параметры неизменяемы. Сохраняются исходные пути, введённый
текст, снимок прочитанного текста, копия изображения и ответы API.
Кнопка «Скопировать в новый запрос» создаёт редактируемый черновик
с теми же путями, режимом текста, введённым текстом и `voice_id`.
**При отправке копии файлы читаются заново**: если оригиналы перемещены,
выберите новые пути. Исторический снимок остаётся неизменным.
Черновики до отправки не сохраняются.

При перезапуске polling сохранённых незавершённых запросов возобновляется,
когда доступен токен. Если приложение завершилось во время POST или ответ
потерялся, запрос помечается как неподтверждённый и **не отправляется заново**:
он мог быть принят и оплачен. Сначала проверьте историю в OpenRouter.
Пока сетевой запрос выполняется, обычное закрытие окна запрещено.

Данные SQLite расположены:

- macOS: `~/Library/Application Support/OpenRouter Video/history.sqlite3`
- Windows: `%LOCALAPPDATA%\OpenRouter Video\history.sqlite3`
- Linux: `~/.local/share/openrouter-video/history.sqlite3`

Каталог можно переопределить через `OPENROUTER_VIDEO_DATA_DIR`.
Токен не записывается в SQLite. Изображения, тексты и ссылки хранятся
локально **без шифрования**; защищайте каталог и резервные копии.
Один каталог истории рассчитан на один одновременно запущенный экземпляр.

## Проверка

Из каталога проекта запустите тесты через `uv`, включая GUI-тесты.
Токен и платные API-запросы не нужны:

```bash
uv run --locked python -m unittest discover -s tests -v
```

Сборка переносимых Python-пакетов:

```bash
uv build
uvx --from ./dist/openrouter_video-0.1.0-py3-none-any.whl openrouter-video
```
